# myFitnessPal 

## Tech Stack

- HTML
- CSS
- JavaScript
- React (18.2.0)
- Redux (4.2.0)
- Redux Thunks (4.2.1)
- Node.js
- Express.js
- MongoDB
- Chakra UI (2.2.4)



## Project Details:
MyFitnessPal is a website that tracks diet and exercise. This is a MERN full stack collaborative project.




# Features and functionalities

- Sign-up/sign-in
- Manage diet
- Add/delete food to breakfast/lunch/snack/dinner
- View blog
